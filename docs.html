Vite (JavaScript / TypeScript)

Cara tercepat untuk SPA dan situs statis. Nusa CSS aktif otomatis begitu diimpor.

1. Buat proyek

npm create vite@latest app -- --template vanilla-ts
  cd app && npm install

2. Salin file dari folder assets

src/
    lib/
      nusa.min.css
      nusa.mjs
      nusa.d.mts      <- salin dari nusa.d.ts, agar TypeScript mengenali tipe
    main.ts
  index.html

3. Impor di main.ts

import './lib/nusa.min.css'
  import { toast, theme, palette, confirmBox } from './lib/nusa.mjs'
  
  document.querySelector('#app')!.innerHTML = `
    <header class="navbar"><b class="text-gradient">Aplikasi saya</b></header>
    <main class="container section stack">
      <h1 class="display">Halo Vite</h1>
      <button class="btn btn-gradient" id="hi">Sapa</button>
    </main>`
  
  document.querySelector('#hi')!.addEventListener('click', () => toast('Halo!', { type: 'success' }))

4. Ubah token tema

/* src/theme.css */
  @import './lib/nusa.min.css';
  :root { --brand: var(--c-teal-600); --r: .5rem }

React (Vite + TypeScript)

Pakai className seperti biasa. Atribut data-nu-* juga jalan di JSX. Di bawah ini ada pembungkus komponen yang bisa langsung disalin.

1. Buat proyek dan salin file

npm create vite@latest app -- --template react-ts
  cd app && npm install
  # salin nusa.min.css, nusa.mjs, nusa.d.mts ke src/lib/

2. Impor sekali di main.tsx

import './lib/nusa.min.css'
  import './lib/nusa.mjs'   // tema, klik modal, tab, salin, dan lainnya aktif otomatis

3. Hook dan komponen animasi: src/lib/useNusa.tsx

import { useEffect, useRef } from 'react'
  import { reveal, countUp } from './nusa.mjs'
  
  // Efek muncul saat di-scroll untuk semua .reveal di dalam elemen
  export function useReveal<T extends HTMLElement>() {
    const ref = useRef<T>(null)
    useEffect(() => { ref.current && reveal(ref.current) }, [])
    return ref
  }
  
  // Angka menghitung naik
  export function Count({ to, prefix = '' }: { to: number; prefix?: string }) {
    const ref = useRef<HTMLSpanElement>(null)
    useEffect(() => { ref.current && countUp(ref.current, to) }, [to])
    return <span ref={ref} data-prefix={prefix}>0</span>
  }

4. Tombol: src/components/Button.tsx

type Props = React.ButtonHTMLAttributes<HTMLButtonElement> & {
    color?: string
    variant?: 'solid' | 'outline' | 'soft'
    size?: 'xs' | 'sm' | 'lg' | 'xl'
    loading?: boolean
  }
  
  export function Button({ color, variant = 'solid', size, loading, className = '', ...p }: Props) {
    const k = variant === 'solid' ? (color ? `btn-${color}` : '') : `btn-${variant}${color ? '-' + color : ''}`
    return <button {...p} className={['btn', k, size && `btn-${size}`, loading && 'btn-loading', className].filter(Boolean).join(' ')} />
  }

5. Modal terkontrol state: src/components/Modal.tsx

import { useEffect, type ReactNode } from 'react'
  
  type Props = { open: boolean; onClose: () => void; title: string; size?: string; children: ReactNode }
  
  export function Modal({ open, onClose, title, size = '', children }: Props) {
    useEffect(() => {
      if (!open) return
      const esc = (e: KeyboardEvent) => e.key === 'Escape' && onClose()
      addEventListener('keydown', esc)
      document.body.classList.add('nu-lock')
      return () => { removeEventListener('keydown', esc); document.body.classList.remove('nu-lock') }
    }, [open])
  
    return (
      <div className={`modal ${size} ${open ? 'open' : ''}`} onClick={e => e.target === e.currentTarget && onClose()}>
        <div className="card">
          <div className="modal-header"><h3>{title}</h3>
            <button className="modal-close" onClick={onClose} aria-label="Tutup"><i className="i i-x" /></button></div>
          <div className="modal-body">{children}</div>
        </div>
      </div>
    )
  }

6. Dipakai di App.tsx

import { useState } from 'react'
  import { toast, theme, confirmBox } from './lib/nusa.mjs'
  import { Button } from './components/Button'
  import { Modal } from './components/Modal'
  import { Count, useReveal } from './lib/useNusa'
  
  export default function App() {
    const [open, setOpen] = useState(false)
    const ref = useReveal<HTMLElement>()
    return (
      <main className="container section stack" ref={ref}>
        <h1 className="display">Dashboard</h1>
        <div className="grid-auto grid-sm">
          <div className="card reveal"><p className="text-muted">Pesanan</p><b className="text-2xl"><Count to={1284} /></b></div>
        </div>
        <div className="row">
          <Button onClick={() => setOpen(true)}>Buka modal</Button>
          <Button variant="outline" color="red" onClick={async () => (await confirmBox('Hapus?')) && toast('Dihapus', { type: 'success' })}>Hapus</Button>
          <Button variant="soft" onClick={() => theme.toggle()}>Tema</Button>
        </div>
        <Modal open={open} onClose={() => setOpen(false)} title="Tambah produk">Isi formulir di sini.</Modal>
      </main>
    )
  }
Jangan panggil init() lagi. Fungsi itu sudah jalan saat impor, dan memanggilnya dua kali menggandakan pendengar klik. Untuk elemen yang dirender belakangan, panggil fungsi spesifik: reveal(el), countUp(el, n), typewriter(el, [...]), sparkline(el, data), donut(el, data). Klik modal, tab, tema, salin, dan tutup alert memakai delegasi, jadi tetap jalan di elemen dinamis.
Next.js: impor CSS di layout.tsx, lalu panggil fungsi Nusa hanya di komponen dengan "use client". Modul ini aman untuk SSR.

Astro

Nusa CSS cocok dengan Astro: CSS dimuat di layout, skrip dibundel otomatis, dan komponen .astro tidak butuh JavaScript tambahan.

1. Buat proyek dan salin file

npm create astro@latest app
  cd app
  # salin nusa.min.css ke src/styles/ dan nusa.mjs ke src/scripts/

2. Layout dasar: src/layouts/Base.astro

---
  import '../styles/nusa.min.css'
  const { title = 'Situs saya' } = Astro.props
  ---
  <html lang="id">
    <head>
      <meta charset="utf-8" />
      <meta name="viewport" content="width=device-width,initial-scale=1,viewport-fit=cover" />
      <title>{title}</title>
      <!-- is:inline agar jalan sebelum halaman tampil (tanpa kedip) -->
      <script is:inline>
        try {
          var t = localStorage.getItem('nusa-theme')
          document.documentElement.classList.toggle('dark', t === 'dark' || (!t && matchMedia('(prefers-color-scheme:dark)').matches))
          var p = localStorage.getItem('nusa-palette')
          p && p !== 'default' && document.documentElement.setAttribute('data-palette', p)
        } catch (e) {}
      </script>
    </head>
    <body>
      <slot />
      <script>import '../scripts/nusa.mjs'</script>
    </body>
  </html>

6. Jika memakai View Transitions

Halaman diganti tanpa muat ulang, jadi terapkan ulang tema dan efek scroll setiap navigasi.

<script>
  import { theme, palette, reveal } from '../scripts/nusa.mjs'
  document.addEventListener('astro:after-swap', () => {
    theme.apply()
    const p = localStorage.getItem('nusa-palette'); p && palette.set(p)
  })
  document.addEventListener('astro:page-load', () => reveal())
  </script>
Atribut seperti data-count, data-type, data-spark, dan data-tilt dibaca saat halaman dimuat. Pada navigasi View Transitions, panggil countUp, typewriter, dan fungsi lain secara manual.

API baru v1.4

Tambahan di nusa.js dan nusa.mjs (tipe TypeScript sudah diperbarui di nusa.d.ts).

import { loading, scrollFx } from './nusa.mjs'
  
  loading.show('Memproses pesanan…')     // overlay layar penuh
  loading.hide()
  loading.bar()                          // bar tipis di atas halaman
  await loading.button(btn, fetch('/api'))   // tombol loading selama promise berjalan
  await loading.box(el, fetch('/api'))       // spinner di dalam sebuah kotak
  scrollFx()                             // navbar .scrolled, .to-top, [data-parallax] (otomatis di init)
Atribut / kelasFungsi
data-nu-toggle="id"Buka/tutup elemen ber-id tersebut (menu hamburger, sidebar). aria-expanded ikut diperbarui.
.navbar-menu.openMenu mobile terbuka. Menutup otomatis saat tautan diklik, klik di luar, atau Esc.
data-parallax="0.2"Elemen bergeser mengikuti scroll (dinonaktifkan jika pengguna memilih mengurangi gerakan).
.to-topTombol kembali ke atas, muncul setelah scroll 500px.
.navbar.scrolledDitambahkan otomatis setelah scroll 8px (bayangan dan latar lebih pekat).
data-filter="#tabel"Input yang menyaring baris tabel.

CSS utility-first yang ringan dan rapi.

Pilih gaya yang cocok: sederhana, modern, atau klasik. Semua warna dan sudut mengikuti satu set variabel.

Utility-first

Spasi, warna, grid, flex, tipografi, dan efek dengan varian hover:, dark:, md:.

Interaktif

Hamburger, dropdown, modal, tab, dan toast hanya dengan atribut data-r-*.

Siap React

Komponen React di ringan-react.mjs memakai class yang sama.

Komponen interaktif

Panel ringkasan. Gunakan tombol panah kiri/kanan untuk berpindah tab.

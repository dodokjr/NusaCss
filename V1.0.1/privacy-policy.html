Privacy Policy

Last updated: 9 November 2026

Halaman ini merupakan template kebijakan privasi untuk website NusaCss. Sesuaikan isinya dengan layanan, analitik, cookie, hosting, dan pemrosesan data yang benar-benar digunakan sebelum dipublikasikan sebagai kebijakan resmi.

1. Information we collect

Website statis ini tidak seharusnya dianggap mengumpulkan data formulir secara otomatis. Jika kamu menambahkan layanan analitik, formulir, autentikasi, atau backend, jelaskan kategori data yang dikumpulkan, tujuan, dan dasar pemrosesannya di bagian ini.

2. Contact form

Form kontak pada versi ini hanya menampilkan pemberitahuan di browser dan belum mengirim data ke server. Jangan memasukkan informasi sensitif ke dalam form sampai endpoint pengiriman yang aman dikonfigurasi.

3. Cookies and local storage

Script website menyimpan preferensi tema (dark/light) di local storage browser dengan key nusa-theme. Data ini digunakan untuk mempertahankan preferensi tampilan dan tidak dikirim ke server oleh script tersebut.

4. Third-party services

Jika menggunakan font eksternal, analytics, CDN, atau layanan pihak ketiga lainnya, cantumkan nama penyedia, jenis data yang mungkin diproses, dan tautan kebijakan privasinya. Versi stylesheet ini memuat font dari Google Fonts.

5. Data security and retention

Jelaskan langkah keamanan, masa penyimpanan, proses penghapusan, serta kontak pengelola data sesuai implementasi aktual website.

6. Changes to this policy

Kebijakan dapat diperbarui ketika fitur atau pemrosesan data berubah. Perbarui tanggal revisi dan informasikan perubahan penting kepada pengguna jika diperlukan.

7. Contact

Untuk pertanyaan privasi, gunakan kanal kontak yang dikelola oleh pemilik project atau buat issue melalui repository NusaCss.

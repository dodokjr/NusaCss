NusaCss developer guide

Nusa CSS v1.4 adalah satu stylesheet berisi variabel desain, komponen, utilitas, dan keyframes animasi dengan prefix nu-. Semua fitur dipakai lewat class dan atribut HTML. Stylesheet ini tidak menyertakan JavaScript.

Setiap contoh di bawah ini berupa pratinjau langsung (dirender di iframe dengan nusa.css asli) beserta kode lengkapnya. Beberapa komponen (modal, navbar mobile, reveal, to-top) hanya menyediakan style untuk state tertentu, misalnya .open, .in, atau .show. Menambah dan menghapus class itu tugas script kamu; contohnya ada di bagian Vanilla JS.

Installation

Hubungkan file CSS di <head>. Untuk website statis, hubungkan stylesheet langsung dari CDN:

<link rel="stylesheet" href="https://nusacss-app.vercel.app/V1.0.1/assets/nusa.css">

Pasang class dark pada <html> untuk dark mode, dan opsional data-palette atau data-style untuk tema:

<html lang="id" class="dark" data-palette="ocean">

Stylesheet memakai oklch() dan color-mix(), jadi butuh browser modern. Efek scroll-* memakai animation-timeline dan otomatis tidak aktif di browser yang belum mendukungnya.

Build purged

nusa.css memuat sekitar 8.800 class (utilitas warna, varian responsif sm: md: lg: xl:, hover:, dark:, dan seterusnya) dengan ukuran sekitar 470 KB. nusa_purged_min.css adalah versi yang sudah dibersihkan dan di-minify, berukuran sekitar 46 KB. File ini hanya berisi sekitar 280 class yang dipakai halaman, ditambah semua variabel, keyframes, dan komponen dasar.

<!-- development: semua class tersedia -->
<link rel="stylesheet" href="assets/nusa.css">

<!-- production: hanya class yang dipakai -->
<link rel="stylesheet" href="assets/nusa_purged_min.css">

Jika kamu menambah class baru yang tidak ada di build purged, misalnya md:grid-cols-4 atau bg-teal-500, class itu tidak akan bekerja sampai kamu membuat ulang build purged atau kembali memakai nusa.css.

Tema & variabel

Semua warna dan radius berasal dari custom property di :root. Ubah variabel untuk menyesuaikan seluruh komponen sekaligus.

:root {
  --bg, --surface, --surface-2   /* latar */
  --text, --muted, --line        /* teks dan garis */
  --brand, --brand-fg, --brand-soft
  --ok, --bad, --warn, --inf     /* warna semantik */
  --r: .625rem;                  /* radius dasar */
  --nav-h: 3.75rem;              /* tinggi navbar */
  --c-indigo-600, --c-sky-500 ...  /* palet 50-900 */
}

Palet tersedia untuk gray, indigo, blue, sky, teal, green, lime, amber, orange, red, pink, dan violet, masing-masing dengan skala 50 sampai 900.

<!-- dark mode -->
<html class="dark">

<!-- palet: ocean | sunset | forest | rose | royal -->
<html data-palette="sunset">

<!-- gaya klasik (radius kecil, font serif) -->
<html data-style="classic">

Palet dan dark mode bisa digabung, misalnya class="dark" data-palette="forest". Warna semantik --ok, --bad, --warn, dan --inf otomatis lebih terang di dark mode.

Warna & background

Warna semantik mengikuti dark mode. Tambahkan /10 sampai /90 untuk transparansi, atau -soft untuk latar lembut.

Font & teks

Ukuran text-2xs sampai text-9xl, ukuran fluid, enam keluarga font, dan efek teks siap pakai.

Ukuran, padding & margin

Pecahan (w-1/2), skala rem (w-64), kata kunci (w-fit), dan batas min-*/max-*. Skala spasi 0–96 (1 satuan = 0,25rem), ditambah padding fluid pad, pad-lg, pad-xl.

Flex & grid

Flexbox lengkap, grid 1–12 kolom, col-span, order, kolom otomatis grid-fit-*, dan masonry lewat columns-*. Gunakan tombol Mobile/Tablet/Desktop pada pratinjau untuk melihat varian responsif.

Posisi, z-index & efek

z-0 sampai z-100 (langkah 10), -z-10, z-max. Gabungkan varian hover:, focus:, active:, group-hover:, dan dark: untuk interaksi tanpa CSS tambahan.

Layout

Class layout memakai ukuran fluid (clamp()) sehingga spacing menyesuaikan layar tanpa breakpoint tambahan.

Class yang tersedia:

  • Container: container, container-sm, container-md, container-lg, container-xl, container-fluid
  • Section: section, section-sm, section-lg, section-xl, section-alt, section-dark
  • Hero: hero, hero-sm, hero-full, hero-media (gambar latar)
  • Susunan: stack / stack-sm / stack-lg, row, row-between, center, split (dua kolom mulai 768px)
  • Grid: grid-auto dengan grid-sm (min 11rem) atau grid-lg (min 22rem), plus grid-cols-1 sampai grid-cols-12
  • Jarak fluid: gap-fluid, gap-fluid-lg, pad, pad-lg, pad-xl
  • Tipografi fluid: display, title, lead, text-fluid-lg sampai text-fluid-3xl, text-balance
  • Lainnya: sticky-top, divider, divider-text, prose (gaya artikel, max 68ch), hide-scrollbar

Utilitas

Nama utilitas mengikuti konvensi utility-first yang umum, sehingga mudah ditebak: p-4, mt-6, gap-3, flex, items-center, justify-between, rounded-xl, shadow-xl, text-2xl, font-bold, w-full, max-w-xl.

<div class="flex items-center justify-between gap-4 p-4 rounded-xl bg-surface border">
  <span class="text-muted text-sm">Status</span>
  <span class="text-brand font-semibold">Aktif</span>
</div>

Warna. Selain palet bernomor (bg-indigo-500, text-green-600, border-red-200, from-sky-400 to-teal-500), ada warna semantik yang mengikuti tema: bg-brand, bg-brand-soft, bg-surface, bg-surface-2, text-brand, text-muted, text-danger, border-line. Opacity dituliskan dengan garis miring, misalnya bg-brand/10.

Varian. Tambahkan prefix untuk kondisi tertentu:

md:grid-cols-3          /* mulai 768px */
hover:bg-brand-soft     /* saat di-hover */
focus:ring-2            /* saat fokus */
dark:text-white         /* saat class "dark" aktif */
group-hover:text-brand  /* saat parent .group di-hover */

Breakpoint: sm: 640px, md: 768px, lg: 1024px, xl: 1280px.

Efek visual: glass, aurora, text-gradient, text-glow, text-outline, shadow-glow, hover-lift, shine, link-underline, marker, drop-cap, caret.

Button & badge

  • Ukuran: btn-xs, btn-sm, btn-lg, btn-xl
  • Bentuk: btn-pill, btn-circle, btn-square, btn-icon, btn-block, btn-group
  • Gaya: btn-outline, btn-soft, btn-ghost, btn-link, btn-glass, btn-dark, btn-gradient, btn-3d
  • Warna: btn-red, btn-green, btn-blue, btn-amber, btn-teal, btn-pink, dan seterusnya, serta btn-danger dan btn-success. Varian outline dan soft memakai pola btn-outline-red dan btn-soft-red.
  • Badge: badge-green, badge-red, badge-amber, badge-gray, badge-count, badge-dot, badge-lg

Tombol dengan disabled atau class disabled otomatis redup dan tidak bisa diklik.

Card

Varian: card-hover (naik saat hover), card-elevated, card-flat, card-brand, card-link, card-overlay, card-flush. Ukuran padding: card-sm, card-lg, card-xl. Bagian dalam: card-header, card-content, card-footer.

Komponen terkait: stat (stat-value, stat-label), pricing dengan price-big dan featured, product, profile, avatar dan avatars, quote, timeline, checklist, progress, skeleton, chip, logo-cloud, gallery, carousel.

Gambar, galeri & avatar

Placeholder .ph (gradient + emoji dari data-ph, tanpa file gambar) dan efek untuk <img>. Untuk foto sungguhan, ganti .ph dengan <img class="img-cover" loading="lazy">.

Navbar

Navbar bersifat sticky. Menu mobile tampil saat .navbar-menu mendapat class open, dan ikon hamburger berubah menjadi X saat aria-expanded="true" pada .navbar-toggle. Tambahkan scrolled setelah halaman di-scroll untuk bayangan dan latar yang lebih pekat.

Varian: navbar-transparent (fixed, transparan sampai scrolled), navbar-dark. Untuk aplikasi: app + sidebar + nav-link (sidebar tampil mulai 768px), appbar, bottom-nav dengan has-bottom-nav pada body, fab, breadcrumb, pagination, tabs dengan tab.

Form & tabel

Elemen form: input, textarea, select, label, field, check, switch, input-group, qty, rating, newsletter.

Varian tabel: table-striped, table-bordered, table-sm, table-lg, table-flat, table-dark, table-card, table-center. Bungkus dengan table-responsive agar bisa di-scroll horizontal di layar kecil.

Alert, modal, toast

Alert: alert-success, alert-warn, alert-error, alert-info, juga per warna (alert-blue, alert-amber, dst), dengan modifier alert-solid, alert-bar, alert-title, alert-close.

Modal tersembunyi sampai diberi class open. Ukuran: modal-sm, modal-lg, modal-xl, modal-full; tipe lain: drawer (dari kanan), sheet (dari bawah), modal-blur. Tambahkan nu-lock pada <body> untuk mengunci scroll saat modal terbuka.

Toast diletakkan di dalam .toasts (kanan bawah) atau .toasts toasts-top (kanan atas), dengan varian toast-success, toast-error, toast-warn. Komponen kecil lain: spinner, loading-overlay, is-loading, kbd, dropdown (berbasis <details>), details.acc (accordion), dan atribut data-tip="..." untuk tooltip.

Ikon

Ikon berupa mask CSS, jadi warnanya mengikuti currentColor dan ukurannya mengikuti font-size. Tidak perlu file SVG atau library tambahan.

Ikon tersedia: i-home, i-user, i-users, i-settings, i-search, i-menu, i-x, i-check, i-plus, i-minus, i-trash, i-edit, i-bell, i-mail, i-phone, i-heart, i-star, i-cart, i-wallet, i-receipt, i-chart, i-calendar, i-clock, i-sun, i-moon, i-lock, i-eye, i-link, i-filter, i-logout, i-tag, i-truck, i-printer, i-copy, i-upload, i-download, i-image, i-info, i-alert, i-globe, i-play, i-arrow-right, i-grid, i-box, i-code.

Efek loading

Spinner, titik, equalizer, skeleton, shimmer, progress bar, dan is-loading untuk kotak yang sedang memuat.

Animate

Animasi dipicu dengan class animate-*. Keyframes memakai prefix nu- (nu-up, nu-fade, nu-zoom, dan lainnya).

  • Sekali jalan (masuk): animate-up, animate-down, animate-left, animate-right, animate-zoom, animate-fade, animate-wiggle
  • Berulang: animate-float, animate-spin, animate-ping, animate-pulse, animate-bounce, animate-gradient, animate-blink
  • Delay animasi: delay-100 sampai delay-700
  • Transisi: transition, transition-colors, transition-transform, duration-150 sampai duration-1000, ease-in, ease-out, ease-in-out, ease-spring, td-200 sampai td-1000 (transition delay)
  • Efek khusus: shimmer, text-shimmer, shine, ripple, marquee, orbit, spark, donut, loader-bar

Jika pengguna mengaktifkan reduce motion di sistemnya, durasi animasi dan transisi otomatis dipangkas hampir nol, dan elemen .reveal langsung tampil.

Reveal & stagger

.reveal menyembunyikan elemen (transparan dan bergeser ke bawah) sampai class in ditambahkan, biasanya lewat IntersectionObserver saat elemen masuk layar.

Arah dan gaya: reveal-left, reveal-right, reveal-zoom, reveal-flip, reveal-blur. Delay transisi: rd-1 sampai rd-6 (0,1 detik per langkah). Class stagger memberi animation-delay bertahap (80 ms per anak, sampai 8 anak pertama) pada elemen yang memakai animate-*.

Scroll effects

Efek berikut dijalankan oleh CSS scroll-driven animation. Tidak perlu JavaScript, tetapi hanya aktif di browser yang mendukung animation-timeline: view().

<h2 class="scroll-fade">Muncul saat di-scroll</h2>
<img class="scroll-scale" src="foto.jpg" alt="">
<p class="scroll-slide">Geser masuk</p>
<span class="scroll-fill">Garis bawah terisi</span>

Class lain yang berkaitan dengan scroll tetapi membutuhkan script kecil: scroll-bar (progress bar di atas halaman; atur width lewat JS), to-top (tombol kembali ke atas; tambahkan show setelah scroll), parallax, [data-tilt], dan scroll-hint (panah yang bergerak naik-turun).

Vanilla JavaScript

Berikut contoh script minimal untuk mengaktifkan state yang dibutuhkan class di atas.

// Dark mode
document.documentElement.classList.toggle("dark");

// Reveal saat masuk layar
const io = new IntersectionObserver((entries) => {
  entries.forEach((e) => {
    if (e.isIntersecting) { e.target.classList.add("in"); io.unobserve(e.target); }
  });
}, { threshold: 0.15 });
document.querySelectorAll(".reveal").forEach((el) => io.observe(el));

// Navbar mobile
const toggle = document.querySelector(".navbar-toggle");
const menu = document.querySelector(".navbar-menu");
toggle.addEventListener("click", () => {
  const open = menu.classList.toggle("open");
  toggle.setAttribute("aria-expanded", open);
});

// Navbar berubah saat di-scroll
addEventListener("scroll", () => {
  document.querySelector(".navbar").classList.toggle("scrolled", scrollY > 8);
}, { passive: true });

// Modal
const modal = document.querySelector("#m1");
modal.classList.add("open");
document.body.classList.add("nu-lock");

React

Nusa CSS hanya berupa stylesheet, jadi di React cukup impor CSS sekali dan pakai className. State seperti open dan in diatur dengan state biasa.

import "./assets/nusa.css";
import { useState } from "react";

export default function Example() {
  const [open, setOpen] = useState(false);

  return (
    <>
      <button className="btn btn-gradient" onClick={() => setOpen(true)}>
        Buka modal
      </button>

      <div className={"modal" + (open ? " open" : "")}>
        <div className="card">
          <div className="modal-header">
            <h3>Halo Nusa</h3>
            <button className="modal-close" onClick={() => setOpen(false)}>&times;</button>
          </div>
          <p className="modal-body animate-up">Dibangun dengan class Nusa CSS.</p>
        </div>
      </div>
    </>
  );
}

Dark mode dan tema tetap diatur lewat class dan atribut pada elemen <html> (document.documentElement). Karena stylesheet tidak bergantung pada DOM tertentu, pendekatan yang sama berlaku untuk Vue, Svelte, atau framework lain. React Native tidak didukung karena tidak memakai CSS.

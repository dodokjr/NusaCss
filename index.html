Pengenalan

Apa itu Nusa CSS?

Nusa CSS adalah framework CSS utility-first yang ringan dan lengkap. Ia memadukan kelas utility ala Tailwind, komponen siap pakai ala Bootstrap, dan layout otomatis, sehingga Anda tidak perlu lagi memikirkan padding, container, atau lebar kolom.

Nama Nusa berarti pulau. Setiap komponen berdiri sendiri, tetapi semuanya tersusun dalam satu gugusan yang rapi dan saling terhubung.

RinganTanpa buildDark mode bawaanResponsif otomatisRamah TypeScriptHTML, React, Vite, Astro

Isi satu paket

nusa.min.css

Stylesheet utama: utility, komponen, ikon, animasi

nusa.js / nusa.mjs

Tema, toast, dialog, grafik mini, efek scroll

nusa.d.ts

Tipe TypeScript untuk Vite, React, dan Astro

Cara kerjanya

1

Pasang

Salin dua file: nusa.min.css dan nusa.js. Tanpa npm, tanpa build.

2

Susun

Pakai container, stack, grid-auto, dan utility seperti p-4 atau md:flex.

3

Percantik

Tambahkan komponen, ikon, palet tema, animasi, dan dialog dengan satu atribut atau satu baris JS.

Catatan browser

Nusa CSS memakai fitur CSS modern (oklch, color-mix, dan backdrop-filter), jadi paling cocok untuk browser keluaran 2023 ke atas.
